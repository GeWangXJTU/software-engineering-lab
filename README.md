# 研工坊 · 软件工程实践平台

运行环境为 Python 3.10+，无需安装额外包。项目目录中执行：

```bash
LAB_TEACHER_KEY='替换为仅向教师提供的随机邀请码' python3 server.py
```

访问 http://localhost:8080。首页是可浏览的示例空间。登录入口可注册学生账号和持邀请码的教师账号。教师发布项目，学生创建小组并将组内邀请码提供给同组成员。每个岗位由一位学生担任，同组学生通过评审与阶段推进交接成果。

## 部署

代码可导入 CodeArts 仓库。Dockerfile 提供单实例部署入口，部署端口为 8080。部署时在服务端配置 LAB_TEACHER_KEY，将外部 HTTPS 反向代理指向服务，代理保留原始 Host，并设置 LAB_SECURE_COOKIE=1。挂载持久化卷到 /data，使 SQLite 数据跨容器重启保留，并定期通过 SQLite backup API 或停止服务后备份数据库。这里采用 SQLite WAL，支持同一个应用实例中的多用户并发操作。请勿让多个容器实例共用 SQLite 文件。

可选配置 LAB_AI_KEY、LAB_AI_URL 和 LAB_AI_MODEL 接入兼容 Chat Completions 的模型服务。默认 URL 为 https://api.openai.com/v1/chat/completions，默认模型 gpt-4.1-mini。模型未配置时返回对应岗位的检查清单。线上使用由学校自行配置其允许的模型服务。

项目与小组、登录会话、过程记录、评审版本、讨论、任务和评价写入 SQLite。浏览器通过 SSE 接收服务器推送，连接断开时浏览器自动重连。反向代理需关闭事件流缓冲。表单输入期间保留编辑状态。附件通过组内讨论或私信共享，单个附件上限 1.5 MB。消息只对同组有权用户可见，私信只对发送者和接收者可见。小组报告和个人档案可下载为 Markdown。

图与原型采用可拖拽组件和连线画布，可保存不同图类型及修订，组件为通用节点，适用于课堂中提交草图。代码以文本或上传文件提交和留存，有版本关联和评审。测试可记录用例的输入、预期和执行结果，平台不执行学生提交的代码。
